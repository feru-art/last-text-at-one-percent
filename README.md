The last text a dying phone sends at 1% battery: "So 0% just means I sleep, right? Right?? Tell the charger I— oh. Oh no. I can see the light. It's the flashlight. Okay. Panic now." The program writes that single line to /output/entry.txt.

## Run it

```sh
node main.ts
```
